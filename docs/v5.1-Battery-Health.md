# v5.1 - Battery Health

Adds battery diagnostics to the Advanced Technician Console.

## Battery metrics

- Design Capacity
- Full Charge Capacity
- Current Remaining Capacity
- Current Charge %
- Battery Health %
- Battery Wear %
- Cycle Count where supported
- Battery status

## Formula

Battery Health % = Full Charge Capacity / Design Capacity x 100

Battery Wear % = 100 - Battery Health %

Current Charge % = Remaining Capacity / Full Charge Capacity x 100

## Native Windows report

The toolkit can also call:

```powershell
powercfg /batteryreport
```

to generate the full Windows battery history report.
