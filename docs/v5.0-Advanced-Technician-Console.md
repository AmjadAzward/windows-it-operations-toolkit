# v5.0 - Advanced Technician Console

v5.0 expands the toolkit without converting it into a separate software product.

## New Modules

- SmartDiagnosis.psm1
- WindowsUpdateTools.psm1
- UserAudit.psm1
- StartupAudit.psm1
- WifiTools.psm1
- PortTools.psm1
- CrashTools.psm1
- SystemExtras.psm1
- CaseLogger.psm1

## Design Goal

Keep the project usable directly from CMD/PowerShell while adding real-world technician workflows, richer diagnostics, safer remediation, incident documentation, and clearer automated recommendations.
