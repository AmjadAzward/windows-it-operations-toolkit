# v4.1 Dashboard Upgrade

The v4.1 dashboard replaces the basic static summary with a fuller IT operations view.

## New sections

- Endpoint health cards
- Device overview
- Network health
- Security status
- Top memory processes
- Top CPU processes
- Core services
- Top error providers
- Recent critical/error events
- Software count
- Battery status

The dashboard remains a local static HTML snapshot for portability and does not expose a network service.
